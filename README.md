# Oxygen Not Included mods

Source, translations and development tooling for **Delivery Temperature Limit (Supercooled)**, a maintained continuation of Delivery Temperature Limit.
The mod lets you set minimum and maximum temperatures for deliveries to storage and buildings, with optional limits for construction materials.

## Develop and release

ONI Mod Pipeline is the supported command-line workflow for validating, building, testing, installing and preparing this mod for manual Workshop upload.
Start with the guide for your task:

| Task                                   | Guide                                                                                        |
| -------------------------------------- | -------------------------------------------------------------------------------------------- |
| Configure a checkout                   | [Getting started](tools/oni-mod-pipeline/manual/setting-up-a-checkout.md)                    |
| Build, test and install changes        | [Developing ONI mods](tools/oni-mod-pipeline/manual/building-testing-and-installing-mods.md) |
| Prepare an immutable release candidate | [Preparing ONI mod releases](tools/oni-mod-pipeline/manual/preparing-releases.md)            |
| Define a mod's pipeline inputs         | [Profile reference](tools/oni-mod-pipeline/manual/profile-reference.md)                      |
| Resolve a diagnostic                   | [Troubleshooting](tools/oni-mod-pipeline/manual/troubleshooting.md)                          |

[ONI mod development workflow](tools/oni-mod-pipeline/manual/development-and-release-workflow.md) explains the command lifecycle and exact-artifact discipline.
The pipeline stops at `ready-for-upload`; a human performs the authenticated Publish action.
