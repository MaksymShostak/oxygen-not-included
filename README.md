# Oxygen Not Included mods

Source, translations and development tooling for **Delivery Temperature Limit (Supercooled)**, a maintained continuation of Delivery Temperature Limit.
The mod lets you set minimum and maximum temperatures for deliveries to storage and buildings, with optional limits for construction materials.

## Develop and release

ONI Mod Pipeline is the supported command-line workflow for validating, building, testing, installing and preparing this mod for manual Workshop upload.
Start with the guide for your task:

| Task                                   | Guide                                                                   |
| -------------------------------------- | ----------------------------------------------------------------------- |
| Configure a checkout                   | [Getting started](docs/guides/getting-started-with-oni-mod-pipeline.md) |
| Build, test and install changes        | [Developing ONI mods](docs/guides/developing-oni-mods.md)               |
| Prepare an immutable release candidate | [Preparing ONI mod releases](docs/guides/preparing-oni-mod-releases.md) |
| Define a mod's pipeline inputs         | [Profile reference](docs/guides/oni-mod-pipeline-profile-reference.md)  |
| Resolve a diagnostic                   | [Troubleshooting](docs/guides/troubleshooting-oni-mod-pipeline.md)      |

[ONI mod development workflow](docs/guides/oni-mod-development-workflow.md) explains the command lifecycle and exact-artifact discipline.
The pipeline stops at `ready-for-upload`; a human performs the authenticated Publish action.
